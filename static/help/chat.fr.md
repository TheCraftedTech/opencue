# Chat et notes

Le panneau **Chat et notes** est une petite messagerie et un carnet de notes à la fois. Vous pouvez **discuter avec les autres appareils** connectés à OpenCue – la console, un iPad, un téléphone – et tenir des **notes et des listes de contrôle** pour le spectacle : une liste de tâches avant l'ouverture des portes, un mémo sur le patch, le déroulé du rappel.

Tout est enregistré **sur le serveur** (l'ordinateur qui exécute OpenCue). Chaque appareil voit les mêmes discussions et les mêmes notes, et elles sont encore là demain.

---

## 1. Ouvrir le panneau

*Édition → **Ajouter un panneau** → Scène et assistant → **Chat et notes*** (sur une tablette, de la même façon). Vous pouvez ajouter le panneau plusieurs fois et les disposer librement ; tous montrent les mêmes discussions et notes.

À gauche se trouve la **liste** des discussions et des notes. Le premier bouton de l'en-tête la masque ; dans un panneau étroit, elle glisse par-dessus le contenu. Le bouton **+** crée une **nouvelle discussion** ou une **nouvelle note**. Sous la liste, vous voyez **votre nom**.

---

## 2. Discuter avec d'autres appareils

- Cliquez sur une discussion, écrivez, envoyez avec **Entrée** – **Maj + Entrée** passe à la ligne.
- Chaque message indique qui l'a écrit et quand. Vos propres messages sont à droite.
- **Votre nom** (en bas à gauche, cliquez pour le changer) se choisit par appareil, par exemple « Régie » ou « iPad scène ». Il est mémorisé sur cet appareil. Tant que vous n'en avez pas choisi, la console s'appelle « Console » et une tablette « Télécommande » suivie d'un numéro.
- Les nouveaux messages apparaissent **immédiatement** sur chaque appareil. Si la discussion n'est pas ouverte sur un appareil, un petit **point** apparaît dans la liste et un court message s'affiche.
- Pendant que quelqu'un écrit, vous voyez **« Nom est en train d'écrire »** sous les messages. Dans une note, **« Nom modifie la note »** s'affiche tant que quelqu'un d'autre y travaille.
- Passez la souris sur un message (sur un écran tactile, les boutons sont toujours visibles) pour **Copier** et **Supprimer**. Supprimer retire le message sur tous les appareils.
- Double-cliquez sur le titre (ou utilisez le crayon) pour **renommer** une discussion ; la corbeille supprime toute la discussion après confirmation.
- **Gras**, *italique*, `code`, ++souligné++ et liens fonctionnent dans les messages comme dans les notes (section 4).

---

## 3. Notes et listes de contrôle

Une note est un texte écrit en **Markdown** – mais vous n'avez pas besoin de connaître le Markdown : la **barre d'outils** s'en charge.

| Bouton | Ce qu'il fait |
|---|---|
| **B**, *I*, U, S | gras, italique, souligné, barré (aussi **Ctrl+B / I / U**) |
| H | titre – cliquez encore pour un plus petit |
| boutons de liste | liste à puces, liste numérotée, **liste de contrôle**, citation, code |

- **Modifier / Aperçu** (en haut à droite) : *Aperçu* montre la note mise en forme. Dans l'aperçu, vous pouvez **cocher directement les cases** – idéal pour une liste que vous parcourez pendant le spectacle. Un double-clic dans l'aperçu lance la modification.
- **Entrée** dans une liste la poursuit avec l'élément suivant ; **Entrée** sur un élément vide termine la liste. **Tab / Maj + Tab** décalent les éléments.
- Dans la liste, une note indique combien de tâches sont terminées, par exemple « 3/5 ».
- Les notes sont **enregistrées automatiquement** un instant après que vous avez cessé d'écrire (« Enregistré » à côté des boutons).

---

## 4. Aide-mémoire Markdown

| Vous écrivez | Vous obtenez |
|---|---|
| `**gras**` | **gras** |
| `*italique*` | *italique* |
| `++souligné++` | souligné |
| `~~barré~~` | barré |
| `# Titre`, `## Plus petit` | titres |
| `- élément` | liste à puces (décalez de deux espaces pour une sous-liste) |
| `1. élément` | liste numérotée |
| `- [ ] tâche` / `- [x] fait` | case à cocher |
| `> citation` | citation |
| `` `code` `` | code |
| `---` | ligne horizontale |
| `[texte](https://...)` | lien |

---

## 5. Bon à savoir

- Les discussions et les notes appartiennent au **programme, pas à un spectacle** : elles restent quand vous chargez un autre spectacle.
- Ce sont des fichiers dans le dossier de données (`notebook`) ; copiez le dossier pour les emporter sur un autre ordinateur.
- **Plusieurs personnes dans la même note :** la dernière sauvegarde l'emporte. Si deux personnes écrivent au même moment, un message vous prévient. Utilisez des notes séparées ou alternez.
- Limites : 300 discussions et notes, 4000 caractères par message, 100 000 par note ; d'une discussion, les 5000 derniers messages sont conservés.
- Toute personne connectée à OpenCue peut tout lire et tout écrire – la discussion n'est **pas privée**. N'y écrivez pas de mots de passe.
- Rien ne quitte votre réseau.
