# Tastenkürzel und Gesten

Alle Tastenkürzel und Touch-Gesten von OpenCue an einer Stelle. Im Programm steht dieselbe Liste unter **Hilfe → Tastenkürzel** und **Steuerung → Tastenkürzel …** – und dort lassen sich die Kürzel des Programms auch **ändern** (Abschnitt 11b).

Auf einer Mac-Tastatur (oder in einem Browser darauf) wirkt `Cmd` wie `Strg`.

---

## 1. Überblick

Die meisten Kürzel sind **global**: Sie wirken, egal wo der Fokus steht – mit einer Regel: **Während du in ein Textfeld tippst, bleiben nur wenige Kürzel aktiv**: `Strg+S`, `Strg+Umschalt+S`, `Strg+F`, `F1`, `F5`, `Strg+F5`, `F11` und `Strg+L`. Alles andere (`Strg+N`, `Strg+O`, `Strg+Q`, `Strg+E`, Pfeiltasten, `Strg+1–9`, Skalierungs-, Zwischenablage- und Rückgängig-Kürzel) bleibt still, damit das Tippen nie gestört wird.

---

## 2. Showfile

| Kürzel | Aktion |
|---|---|
| `Strg+N` | Neues Showfile (fragt zuerst nach, wenn es ungespeicherte Änderungen gibt) |
| `Strg+O` | Showfile öffnen (öffnet den Dateimanager bei *Shows*) |
| `Strg+M` | Dateimanager (alle Dateien: Shows, Layouts, Bühnen, Modelle, Medien, Effekte …) |
| `Strg+L` | **Bildschirm sperren** (Menü *Steuerung → Bildschirm sperren*; braucht *Einstellungen → Sicherheit → Sichermodus verwenden*; an einem Fernzugriffs-Gerät: abmelden; im Bedienmodus: fragt das Passwort zum Verlassen) |
| `Strg+S` | Showfile **und** Layout dieser Konsole speichern (eine Show ohne Namen öffnet *Speichern unter*) |
| `Strg+Umschalt+S` | Showfile unter neuem Namen speichern |
| `Strg+Q` | OpenCue beenden (fragt vorher nach dem Speichern) |

`Strg+S` funktioniert auch, während du in ein Namensfeld tippst, zum Beispiel im Dialog *Speichern unter*.

## 3. Ansicht und Oberfläche

| Kürzel | Aktion |
|---|---|
| `?` | **Diese Übersicht aller Tastenkürzel ein- / ausblenden** (nicht beim Tippen in ein Feld und nicht über einem anderen Dialog) |
| `F1` | **Anleitungen** öffnen (alle Handbücher im Programm, auch offline). Darin sucht `Strg+F`, `Enter` / `Umschalt+Enter` springen zum nächsten / vorigen Treffer, `Esc` löscht die Suche |
| `F5` | **Layout neu laden**: das aktuelle Layout wird wie bei einem Layout-Wechsel noch einmal geladen und **alle Panels werden neu aufgebaut** (hilft, wenn nach dem Start etwas – zum Beispiel die 3D-Simulation – nicht richtig erschienen ist). Bei ungespeicherten Layout-Änderungen wird nichts aus der Datei geholt: die Panels werden nur neu aufgebaut, deine Änderungen bleiben. Auch unter *Ansicht → Layout neu laden* |
| `Strg+F5` | **Ganze Oberfläche neu laden** (wie das Neuladen einer Webseite; das Gerät bekommt danach sein Layout zurück). Auch unter *Ansicht → Oberfläche neu laden* |
| `F11` | Vollbild (Konsolenfenster oder Browser dieses Geräts) |
| `Strg +` / `Strg =` | Oberfläche vergrößern (GUI-Skalierung, Schritte von 5 %) |
| `Strg -` | Oberfläche verkleinern |
| `Strg+0` | Skalierung auf 100 % zurücksetzen |
| `Strg+Umschalt+L` | Sprache wechseln (der Reihe nach: Englisch, Deutsch, Französisch, Niederländisch, Italienisch, Spanisch) |
| `Strg+F` | **Befehls-Konsole** öffnen / schließen: Befehlszeile mit Ziffernblock und Befehlstasten in einem Fenster – auch ohne diese Panels im Layout; der Cursor steht sofort im Eingabefeld |
| `Esc` | Oberstes Dialogfenster, Panel-Fenster oder Menü schließen / abbrechen – ein Druck schließt **einen** Dialog (die Einstellungen fragen bei Änderungen nach) |

Die GUI-Skalierung (50–200 %) wird **pro Gerät** gespeichert: ein Tablet kann groß sein, während die Konsole klein bleibt.

**Panel als Fenster:** Unter **Ansicht → Panel als Fenster öffnen** lässt sich jedes Panel (außer Knopf, Fader und Schalter) kurz als Fenster öffnen, ohne dass es im Layout liegt. Jedes Fenster hat dieselbe Größe und steht in der Mitte; `Esc`, das × oder ein Klick daneben schließen es. Solange ein Panel-Fenster offen ist, wechseln die Pfeiltasten kein Layout.

## 4. Layouts

| Kürzel | Aktion |
|---|---|
| `Strg+1` … `Strg+9` | Layout 1 bis 9 laden (Favoriten zuerst, dann A–Z) |
| `←` / `→` | Vorheriges / nächstes Layout (nicht in Textfeldern, Dialogen, Menüs oder im Bearbeitungsmodus) |
| Horizontal wischen | Vorheriges / nächstes Layout auf Touch-Geräten (*Einstellungen → Allgemein → Layout per Wischgeste wechseln*, pro Gerät) |

Beim Laden eines Layouts gehen ungespeicherte Änderungen des aktuellen verloren. Die Reihenfolge ist dieselbe wie unter **Ansicht → Layouts**.

---

## 5. Panel-Bearbeitungsmodus

Im Bearbeitungsmodus (**Bearbeiten → Panels bearbeiten**) lassen sich Panels verschieben, in der Größe ändern und einstellen.

| Kürzel | Aktion |
|---|---|
| `Strg+E` | Bearbeitungsmodus ein- / ausschalten |
| Klick auf ein Panel | Markiert es (dünner Akzentrahmen) |
| `Umschalt`/`Strg` + Klick | Panel zur Markierung hinzufügen / daraus entfernen |
| Klick auf leere Arbeitsfläche | Hebt die Markierung auf |
| `Strg+C` / `Strg+X` / `Strg+V` | Markierte Panels kopieren / ausschneiden / einfügen (die Zwischenablage überlebt einen Layoutwechsel) |
| `Strg+Z` | Letzte Panel-Änderung rückgängig |
| `Strg+Y` oder `Strg+Umschalt+Z` | Wiederholen |
| Rechtsklick → *Duplizieren* | Kopiert die markierten (oder angeklickten) Panels mit kleinem Versatz |

Im **Bearbeitungsmodus** gelten `Strg+Z` / `Strg+Y` für die Anordnung der Panels. **Außerhalb** davon machen sie Änderungen am **Inhalt der Show** rückgängig (siehe unten, *Rückgängig und Wiederholen*).

Beim Verlassen des Bearbeitungsmodus mit ungespeicherten Änderungen fragt OpenCue: **Speichern**, **Änderungen verwerfen** (lädt das gespeicherte Layout neu) oder **Weiter bearbeiten**.

## 6. Scheinwerferliste und Programmer

| Aktion | So geht's |
|---|---|
| Einen Scheinwerfer auswählen | Klick / Tippen auf die Kachel |
| Mehrere auswählen | **Lasso**: einen Rahmen über die Kacheln ziehen (Maus und Touch); das Lasso bleibt im eigenen Panel |
| Ausgewählte Scheinwerfer löschen | `Entf` oder `Rücktaste` (fragt nach) |
| Pan-/Tilt-Wert fein ändern | Auf dem Zahlenfeld nach oben/unten **wischen** (grob: 2 px pro Schritt, fein: 4 px pro Feinschritt); Tippen zum Eintippen |
| Kontextmenü öffnen | Rechtsklick (Maus) oder langes Drücken (Touch) auf einen Scheinwerfer oder freien Platz |

## 7. Befehlszeile

| Taste | Wirkung |
|---|---|
| `Enter` | Befehl ausführen |
| `↑` / `↓` | Älterer / neuerer Befehl aus dem Verlauf (nach unten zurück zum Entwurf) |
| `Tab` | Ersten Vorschlag übernehmen; jeder weitere `Tab` wechselt zum nächsten |
| `Umschalt+Tab` | Rückwärts durch die Vorschläge |
| `Esc` | Vorschlagsliste schließen (in der Befehls-Konsole: die Konsole schließen) |

Mit `Strg+F` erscheint die **Befehls-Konsole**: oben die Befehlszeile, darunter Ziffernblock und Befehlstasten – zum schnellen Tippen per Tastatur oder Hand. Was du tippst, steht auch in jeder anderen Befehlszeile (gemeinsamer Eingabepuffer).

Einzelheiten zu den Befehlen: *Befehlsreferenz*.

## 8. Effekt-Studio

|---|---|

| `Tab` | Fügt zwei Leerzeichen ein |
| `Enter` | Neue Zeile mit der Einrückung der vorigen (nach `{` zwei Leerzeichen mehr) |

## 9. 3D-Simulation – Bearbeitungsmodus

Diese Kürzel wirken in der 3D-Simulation nur beim Bauen (Modi *Bauen* / *Scheinwerfer*), nicht im Modus *Ansicht*.

| Kürzel | Aktion |
|---|---|
| `Strg+C` / `Strg+X` / `Strg+V` | Objekte kopieren / ausschneiden / einfügen |
| `Strg+D` | Gewähltes Objekt duplizieren (nochmals drücken wiederholt den Versatz) |
| `Entf` / `Rücktaste` | Gewähltes Objekt löschen (fragt nach); im Scheinwerfer-Modus: Scheinwerfer von der Bühne nehmen |
| `Esc` | Auswahl aufheben |
| `Umschalt` + Klick | Objekt zur Auswahl hinzufügen / daraus entfernen |
| Pfeiltasten | Auswahl verschieben (mit `Umschalt` fünfmal so weit); solange etwas gewählt ist, wechseln die Pfeile kein Layout |
| `Strg+Z` | Rückgängig |
| `Strg+Y` oder `Strg+Umschalt+Z` | Wiederholen |

Scheinwerfer gibt es auf einer Bühne nur einmal, deshalb sind Kopieren, Ausschneiden und Duplizieren im Scheinwerfer-Modus abgeschaltet.

Solange du zielst („Punkt in 3D-Simulation setzen“ in der Scheinwerfer-Steuerung), beendet `Esc` das Zielen.

## 10. Touch-Gesten

| Geste | Entspricht |
|---|---|
| Langes Drücken | Rechtsklick (Kontextmenü) |
| Langes Drücken auf ein Element mit Tooltip | Zeigt den Tooltip |
| Doppeltippen | Doppelklick |
| Horizontal wischen (wenn eingeschaltet) | Vorheriges / nächstes Layout |
| Wischen auf einem Pan-/Tilt-Zahlenfeld | Wert ändern (grob / fein) |

Panel-Griffe und Werkzeugleisten-Knöpfe haben eine Touch-Fläche von mindestens 44 × 44 px. Die Layout-Wischgeste wird an der Richtung der ersten Bewegung erkannt (höchstens 25° von der Waagerechten, mindestens 40 % der Breite) und startet nie auf Elementen mit eigener Ziehfunktion (Fader, Lasso-Kacheln, Wisch-Zahlenfelder, Eingabefelder, Farbrad, Spalten- und Panel-Griffe). Senkrechtes Scrollen bleibt Scrollen.

## 11. Eigene Tastaturbelegung

Eine eigene Taste oder Tastenkombination kann einen **Befehl der Befehlszeile** auslösen – zum Beispiel `Strg+H` für `Blackout` oder die Leertaste für `Cuelist Main Go`. Du öffnest die Liste über **Steuerung → Eigene Tastaturbelegung …** oder über den Knopf unten im Dialog *Tastenkürzel*.

**Eine Taste für den nächsten Cue:** oben im Dialog unter *Schnellstart* auf **Nächster Cue (Go)** klicken (oder *Voriger Cue*, *Pause*, *Blackout*): Es erscheint eine neue Zeile mit dem Befehl `Go`; dann in ihr Tastenfeld klicken und die Taste drücken – zum Beispiel die Leertaste oder eine Taste einer zweiten Tastatur / eines Ziffernblocks (im Dialog *Taste festlegen* **Nur diese Tastatur** wählen). `Go` startet den nächsten Cue der aktiven Cue-Liste; `Cuelist Main Go` immer den dieser Liste.

Jede Zeile hat von links nach rechts:

| Feld | Bedeutung |
|---|---|
| **Aktiv** | Schaltet die Zeile ein oder aus, ohne sie zu löschen. |
| **Taste** | Zeigt die Taste oder Kombination. Ein Klick darauf oder auf den **Tastatur-Knopf** daneben öffnet den Dialog **Taste festlegen**: Dort hast du **10 Sekunden** Zeit, die Taste oder Kombination zu drücken (z. B. `Strg` und `H` zusammen) – aufgenommen wird vom ersten Druck, bis alles wieder losgelassen ist. `Esc` bricht ab, der Knopf neben dem Feld nimmt neu auf. Darunter wählst du, wofür sie gilt: **Alle Tastaturen** oder **Nur diese Tastatur**. Nur über diesen Dialog bekommt eine Zeile ihre Taste. |
| **Befehl** | Der Befehl, wie du ihn in die Befehlszeile tippen würdest. |
| **Ausführen** | An: der Befehl läuft sofort. Aus: er wird nur in die Befehlszeile **geschrieben** (du bestätigst selbst). |
| **Im Verlauf** | An: der Befehl erscheint im Verlauf der Befehlszeile. |
| Mülleimer | Löscht die Zeile (nach einer Rückfrage). |

Mit **Neue Tastenkombination** unten kommen beliebig viele leere Zeilen dazu (ohne Aufnahme). Änderungen gelten sofort und auf allen Geräten, an denen eine Tastatur hängt (auch am iPad).

**Sichern und weitergeben:** Unten im Dialog speichert **Exportieren …** die Belegung als Datei (`opencue-keyboard-mapping.json`), **Importieren …** liest eine solche Datei ein. Die Zeilen kommen **neu dazu**; Tasten, die das Programm oder eine andere Zeile schon belegt, werden übersprungen (die Meldung nennt die Zahl).

**Gut zu wissen**

- Kombinationen, die das Programm oder der Browser schon benutzt (`Strg+S`, `Strg+1…9`, `←`/`→`, `F5` …), werden beim Aufnehmen abgelehnt; jede Kombination kann nur einmal vergeben werden.
- Beim **Tippen in einem Eingabefeld** gelten nur Kombinationen mit `Strg`. Bei offenem Dialog lösen einfache Tasten nichts aus, und bei offenem Dialog *Eigene Tastaturbelegung* gar nichts.
- Der Befehl läuft beim **Drücken** der Taste (nicht beim Loslassen). Eine gehaltene Taste löst ihn nur **einmal** aus.
- Eine Kombination darf **mehrere Haupttasten** haben, z. B. `Strg+H+J`: sie gilt, sobald alle gedrückt sind (die Reihenfolge ist egal). Gibt es zusätzlich `Strg+H`, wartet diese kürzere Kombination einen Moment, ob noch `J` dazukommt.
- Ist eine Kombination schon vom Programm oder vom Browser belegt (auch als Teil einer längeren, z. B. `Strg+S+J`), nimmt OpenCue sie nicht an und zeigt oben im Dialog eine Meldung.
- Die Tasten werden unabhängig von der Tastaturbelegung gespeichert (die Taste `Z` bleibt die Taste an derselben Stelle). Der Ziffernblock heißt `Num1` … `Num9`.

**Taste einer bestimmten Tastatur (z. B. Macropad, nur Windows)**

Im Dialog **Taste festlegen** (Tastatur-Knopf einer Zeile) drückst du die Taste auf der gewünschten Tastatur. An der Konsole unter Windows erkennt OpenCue, von **welcher** Tastatur sie kommt (der Name steht unter dem Feld), und du wählst **Alle Tastaturen** oder **Nur diese Tastatur**. Auf einem Tablet oder ohne Windows nimmt der Browser auf und es gilt immer „Alle Tastaturen“. Eine Taste gilt entweder für alle Tastaturen oder für bestimmte – nicht beides gleichzeitig. Eine Zeile „nur diese Tastatur“ löst nur aus, wenn die Taste auf genau dieser Tastatur gedrückt wird – auch wenn OpenCue nicht im Vordergrund ist. Die Zeile zeigt die Tastatur darunter an.

- Das geht nur **an der Konsole selbst** unter Windows, nicht von einem Tablet aus.
- OpenCue **hört nur mit, solange** es mindestens eine eingeschaltete Zeile für eine bestimmte Tastatur gibt (oder beim Aufnehmen). Es wertet nur die Tastaturen aus, die in der Liste stehen; alles andere wird sofort verworfen und nie gespeichert.
- Windows meldet die Taste nur, es **blockiert** sie nicht: Sie erreicht trotzdem auch das gerade aktive Programm (z. B. als Zeichen in einem Textfeld). Für ein Macropad am besten Tasten wählen, die sonst nichts tun – etwa `F13` bis `F24` oder den Ziffernblock.
- Manche Tastaturen melden sich als mehrere Geräte (z. B. Tasten und Mediatasten getrennt). Das erkennt OpenCue beim Aufnehmen von selbst.
- Zwei verschiedene Tastaturen dürfen dieselbe Taste unterschiedlich belegen. Eine doppelte Meldung desselben Tastendrucks (innerhalb von 80 ms) löst nur einmal aus.

## 11b. Die Kürzel des Programms ändern

Die Kürzel, die das Programm schon hat (`Strg+S`, `F11`, `Strg+E` …), lassen sich auf andere Tasten legen oder abschalten. Öffne **Steuerung → Tastenkürzel …** und klicke unten auf **Kürzel bearbeiten**:

1. Jede änderbare Zeile hat einen gestrichelten Rahmen um ihre Taste. **Die Taste anklicken**, die neue Kombination drücken und **loslassen** – sie ist sofort gesetzt (während du hältst, steht *Tasten drücken …* da). `Esc` bricht ab.
2. Das **Kreuz** neben einer Zeile schaltet das Kürzel **ab**, der **Pfeil** stellt die Standardtaste wieder her. **Alle Standardtasten wiederherstellen** setzt alles zurück. **Fertig** beendet das Bearbeiten.
3. Geänderte Tasten stehen in der Akzentfarbe hier, in den Menüs (zum Beispiel *Datei → Showfile speichern*) und im Dialog *Eigene Tastaturbelegung*, der vergebene Tasten ablehnt.

OpenCue lehnt eine Kombination ab, die schon benutzt wird (von einem anderen Kürzel, einer eigenen Tastenbelegung oder vom Browser / von Windows – zum Beispiel `Strg+W`). Ein Programm-Kürzel hat **eine Haupttaste plus Strg, Alt oder Umschalt**; ein einzelner Buchstabe oder eine Ziffer wird abgelehnt, weil sie das Tippen blockieren würde – Funktionstasten (`F1` … `F24`) gehen allein. Die Änderung gilt für **alle Geräte** der Konsole.

Nicht änderbar (sie hängen von der Situation ab): `Esc`, `Strg+C / X / V` für Panels, `Strg+1 … 9` für Layouts, die Pfeiltasten und die Tasten der 3D-Bearbeitung.

## Rückgängig und Wiederholen (Inhalt der Show)

Außerhalb des Bearbeitungsmodus der Panels machen `Strg+Z` und `Strg+Y` (oder `Strg+Umschalt+Z`) – sowie *Bearbeiten → Rückgängig / Wiederholen* – alles rückgängig, was **in der Showfile gespeichert wird**, und die Bedienung davor:

- **Cues und Cue-Listen:** speichern, aktualisieren, Zeiten / Auslöser / Namen ändern (auch mehrere auf einmal), kopieren, löschen, Listen anlegen, umbenennen, ordnen, löschen;
- **Variablen** und ihre Gruppen, **Scheinwerfer-Gruppen**, das **Patch** (Scheinwerfer anlegen, löschen, umadressieren, umbenennen, anordnen), **Effekte** (Definitionen und Gruppen), **Zeitplan** und **Timeline-Befehlsspuren**;
- die **Auswahl** der Scheinwerfer;
- **Programmer-Werte** (Farbe, Position, Helligkeit, Beam …) – ein Fader-Zug oder ein Befehl wie `At 80` ist **ein** Schritt; auch der DMX-Stand der betroffenen Scheinwerfer geht zurück;
- **laufende Effekte:** einen Effekt auf Scheinwerfer anwenden oder abwählen;
- der **Executor-Fader** einer Cue-Liste (ein Zug = ein Schritt).

Eine kurze Meldung nennt, was rückgängig gemacht wurde. Schnelle gleichartige Änderungen (zum Beispiel eine Wischgeste auf einer Zeit oder ein Fader-Zug) zählen als **ein** Schritt; der Verlauf hält die letzten 100 Schritte. Ein neuer Show-Start (*Neu*, *Öffnen*) leert ihn.

**Go und Back (Schalter):** Ob auch **Go / Back / Springen** (und ein `Go` per Befehl) rückgängig gemacht werden – dann springt `Strg+Z` zum vorigen Cue zurück. Vorgabe: **aus**, damit du in einer Aufführung nie versehentlich einen Cue zurücknimmst. Den Schalter findest du als Symbol (Rückgängig-Pfeil mit Play-Dreieck) in der Toolbar **und** unter *Einstellungen → Weitere Optionen → Schnellschalter* – dort geht er auch, wenn das Symbol in der Toolbar ausgeblendet ist.

**Nicht dabei:** Einstellungen, Go über MIDI / OSC / Timecode und Änderungen über die REST-Schnittstelle. In einem offenen Dialog und in Textfeldern tun die Kürzel nichts. Die Tasten lassen sich unter *Tastenkürzel → Kürzel bearbeiten* umbelegen.
