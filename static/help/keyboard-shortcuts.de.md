# Tastenkürzel und Gesten

Alle Tastenkürzel und Touch-Gesten von OpenCue an einer Stelle. Im Programm steht dieselbe Liste unter **Hilfe → Tastenkürzel**.

Auf einer Mac-Tastatur (oder in einem Browser darauf) wirkt `Cmd` wie `Strg`.

---

## 1. Überblick

Die meisten Kürzel sind **global**: Sie wirken, egal wo der Fokus steht – mit einer Regel: **Während du in ein Textfeld tippst, bleiben nur drei Kürzel aktiv**: `Strg+S`, `Strg+Umschalt+S` und `F11`. Alles andere (`Strg+N`, `Strg+O`, `Strg+Q`, `Strg+E`, Pfeiltasten, `Strg+1–9`, Skalierungs-, Zwischenablage- und Rückgängig-Kürzel) bleibt still, damit das Tippen nie gestört wird.

---

## 2. Showfile

| Kürzel | Aktion |
|---|---|
| `Strg+N` | Neues Showfile (fragt zuerst nach, wenn es ungespeicherte Änderungen gibt) |
| `Strg+O` | Showfile öffnen (öffnet den Dateimanager bei *Shows*) |
| `Strg+S` | Showfile **und** Layout dieser Konsole speichern (eine Show ohne Namen öffnet *Speichern unter*) |
| `Strg+Umschalt+S` | Showfile unter neuem Namen speichern |
| `Strg+Q` | OpenCue beenden (fragt vorher nach dem Speichern) |

`Strg+S` funktioniert auch, während du in ein Namensfeld tippst, zum Beispiel im Dialog *Speichern unter*.

---

## 3. Ansicht und Oberfläche

| Kürzel | Aktion |
|---|---|
| `F11` | Vollbild (Konsolenfenster oder Browser dieses Geräts) |
| `Strg +` / `Strg =` | Oberfläche vergrößern (GUI-Skalierung, Schritte von 5 %) |
| `Strg -` | Oberfläche verkleinern |
| `Strg+0` | Skalierung auf 100 % zurücksetzen |
| `Strg+Umschalt+L` | Sprache wechseln (Englisch ⇄ Deutsch) |
| `Esc` | Oberstes Dialogfenster oder Menü schließen |

Die GUI-Skalierung (50–200 %) wird **pro Gerät** gespeichert: ein Tablet kann groß sein, während die Konsole klein bleibt.

---

## 4. Layouts

| Kürzel | Aktion |
|---|---|
| `Strg+1` … `Strg+9` | Layout 1 bis 9 laden (Favoriten zuerst, dann A–Z) |
| `←` / `→` | Vorheriges / nächstes Layout (nicht in Textfeldern, Dialogen, Menüs oder im Bearbeitungsmodus) |
| Horizontal wischen | Vorheriges / nächstes Layout auf Touch-Geräten (*Einstellungen → Allgemein → Layout per Wischgeste wechseln*, pro Gerät) |

Beim Laden eines Layouts gehen ungespeicherte Änderungen des aktuellen verloren. Die Reihenfolge ist dieselbe wie unter **Ansicht → Layouts**.

---

## 5. Panel-Bearbeitungsmodus

Im Bearbeitungsmodus (**Bearbeiten → Panels bearbeiten**) lassen sich Panels verschieben, in der Größe ändern und einstellen.

| Kürzel | Aktion |
|---|---|
| `Strg+E` | Bearbeitungsmodus ein- / ausschalten |
| Klick auf ein Panel | Markiert es (dünner Akzentrahmen) |
| `Umschalt`/`Strg` + Klick | Panel zur Markierung hinzufügen / daraus entfernen |
| Klick auf leere Arbeitsfläche | Hebt die Markierung auf |
| `Strg+C` / `Strg+X` / `Strg+V` | Markierte Panels kopieren / ausschneiden / einfügen (die Zwischenablage überlebt einen Layoutwechsel) |
| `Strg+Z` | Letzte Panel-Änderung rückgängig |
| `Strg+Y` oder `Strg+Umschalt+Z` | Wiederholen |
| Rechtsklick → *Duplizieren* | Kopiert die markierten (oder angeklickten) Panels mit kleinem Versatz |

Rückgängig und Wiederholen für Panels funktionieren nur **im Bearbeitungsmodus**; außerhalb tun die Kürzel nichts.

Beim Verlassen des Bearbeitungsmodus mit ungespeicherten Änderungen fragt OpenCue: **Speichern**, **Änderungen verwerfen** (lädt das gespeicherte Layout neu) oder **Weiter bearbeiten**.

---

## 6. Scheinwerferliste und Programmer

| Aktion | So geht's |
|---|---|
| Einen Scheinwerfer auswählen | Klick / Tippen auf die Kachel |
| Mehrere auswählen | **Lasso**: einen Rahmen über die Kacheln ziehen (Maus und Touch); das Lasso bleibt im eigenen Panel |
| Ausgewählte Scheinwerfer löschen | `Entf` oder `Rücktaste` (fragt nach) |
| Pan-/Tilt-Wert fein ändern | Auf dem Zahlenfeld nach oben/unten **wischen** (grob: 2 px pro Schritt, fein: 4 px pro Feinschritt); Tippen zum Eintippen |
| Kontextmenü öffnen | Rechtsklick (Maus) oder langes Drücken (Touch) auf einen Scheinwerfer oder freien Platz |

---

## 7. Befehlszeile

| Taste | Wirkung |
|---|---|
| `Enter` | Befehl ausführen |
| `↑` / `↓` | Älterer / neuerer Befehl aus dem Verlauf (nach unten zurück zum Entwurf) |
| `Tab` | Ersten Vorschlag übernehmen; jeder weitere `Tab` wechselt zum nächsten |
| `Umschalt+Tab` | Rückwärts durch die Vorschläge |
| `Esc` | Vorschlagsliste schließen |

Einzelheiten zu den Befehlen: *Befehlsreferenz*.

---

## 8. Effekt-Studio

| Kürzel | Aktion |
|---|---|
| `Strg+S` | Effekt speichern (**nicht** die Show), solange der Cursor im Skript steht |
| `Tab` | Fügt zwei Leerzeichen ein |
| `Enter` | Neue Zeile mit der Einrückung der vorigen (nach `{` zwei Leerzeichen mehr) |

---

## 9. 3D-Simulation – Bearbeitungsmodus

Diese Kürzel wirken in der 3D-Simulation nur beim Bauen (Modi *Bauen* / *Scheinwerfer*), nicht im Modus *Ansicht*.

| Kürzel | Aktion |
|---|---|
| `Strg+C` / `Strg+X` / `Strg+V` | Objekte kopieren / ausschneiden / einfügen |
| `Strg+D` | Gewähltes Objekt duplizieren (nochmals drücken wiederholt den Versatz) |
| `Entf` / `Rücktaste` | Gewähltes Objekt löschen (fragt nach); im Scheinwerfer-Modus: Scheinwerfer von der Bühne nehmen |
| `Esc` | Auswahl aufheben |
| `Umschalt` + Klick | Objekt zur Auswahl hinzufügen / daraus entfernen |
| Pfeiltasten | Auswahl verschieben (mit `Umschalt` fünfmal so weit); solange etwas gewählt ist, wechseln die Pfeile kein Layout |
| `Strg+Z` | Rückgängig |
| `Strg+Y` oder `Strg+Umschalt+Z` | Wiederholen |

Scheinwerfer gibt es auf einer Bühne nur einmal, deshalb sind Kopieren, Ausschneiden und Duplizieren im Scheinwerfer-Modus abgeschaltet.

Solange du zielst („Punkt in 3D-Simulation setzen“ in der Scheinwerfer-Steuerung), beendet `Esc` das Zielen.

---

## 10. Touch-Gesten

| Geste | Entspricht |
|---|---|
| Langes Drücken | Rechtsklick (Kontextmenü) |
| Langes Drücken auf ein Element mit Tooltip | Zeigt den Tooltip |
| Doppeltippen | Doppelklick |
| Horizontal wischen (wenn eingeschaltet) | Vorheriges / nächstes Layout |
| Wischen auf einem Pan-/Tilt-Zahlenfeld | Wert ändern (grob / fein) |

Panel-Griffe und Werkzeugleisten-Knöpfe haben eine Touch-Fläche von mindestens 44 × 44 px. Die Layout-Wischgeste wird an der Richtung der ersten Bewegung erkannt (höchstens 25° von der Waagerechten, mindestens 40 % der Breite) und startet nie auf Elementen mit eigener Ziehfunktion (Fader, Lasso-Kacheln, Wisch-Zahlenfelder, Eingabefelder, Farbrad, Spalten- und Panel-Griffe). Senkrechtes Scrollen bleibt Scrollen.

## 11. Spickzettel

```
Strg+N  Neue Show          Strg+O  Show öffnen        Strg+S  Speichern     Strg+Umschalt+S  Speichern unter
Strg+E  Panels bearbeiten  Strg+Z / Strg+Y  Rückgängig / Wiederholen (Bearbeitungsmodus)
Strg+C / X / V  Panels kopieren / ausschneiden / einfügen (Bearbeitungsmodus)
Strg+1…9  Layout laden     ← / →  Vorheriges / nächstes Layout
Strg +  Strg -  Strg+0     GUI-Skalierung größer / kleiner / 100 %
Strg+Umschalt+L  Sprache   F11  Vollbild        Strg+Q  Beenden      Esc  Dialog schließen
```
