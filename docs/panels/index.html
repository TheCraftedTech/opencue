Panels

OpenCue is built from panels that you place freely. Here is every panel type – add them through Edit → Add Panel and combine them into your own layouts.

Programming

DMX Monitor

Shows the DMX values of the universes live.

Exactly what is being sent, channel by channel and universe by universe – the fixtures are outlined so you can find them.

Fixture List

List of patched fixtures: select, patch, edit.

The patch table with one row per fixture: number, name, type, universe, address and channel count. Add fixtures here.

Fixture Control

Set values of the selected fixtures (dimmer, color, position ...).

Dimmer, position, colour, beam, focus and direct DMX access for the selected fixtures, plus the tile grid for selecting them.

Variables / Effects

Recall stored variables and effects quickly.

Reusable colours, positions and beams. A variable is a live reference: change it once and everything that uses it follows.

Effect Studio

Design effects: curves, speed, offset.

Write your own effects in a small C++/Arduino-like script language – with a live preview curve and built-in help.

Cues and playback

Cue List

Create, edit and play cue lists.

Store, update, edit and play the cues of a list, with fade times, triggers and move-in-black.

Executor (cue playback)

Run one cue list with fader, Go and pause.

Plays one cue list with Go, Pause, Back and Stop and a mix fader between your manual values and the cue.

Input and control

Command Line

Type and run commands.

Type commands like Fixture 1 Thru 4 At 80 – Tab completes, and the input is checked as you type.

Command Numpad

Number pad for entering commands by touch.

Enter commands without a keyboard – made for tablets and touch screens.

Command Buttons

Buttons for frequently used commands.

One tap for Fixture, Group, Store, Go, Blackout and the other everyday commands.

Button

Your own button that runs a command.

Name it and give it a command such as Go Cue 1 or Blackout – build your own surface.

Fader

Your own fader, for example for a dimmer or master.

Use {value} in its command, for example Fixture 1 Thru 4 At {value}.

Media and time

Timecode

Global timeline with start, stop, speed and cue triggering.

Run, pause, step and jump; change the speed from 0.1× to 8×. Cues can start by timecode.

Video/Audio Player

Plays video or audio, optionally in sync with the timecode.

Add media files to your show and play them in sync with the timecode or freely.

Livestream / Camera

Shows a livestream (camera address) or a camera attached to the main device.

IP cameras by MJPEG, HLS or video URL, or a camera on the main computer – with a full-screen view.

Stage

3D Simulation

Shows the stage in 3D, with the light of your fixtures.

Light cones, light pools, gobos and strobe follow the DMX signal live. Build a stage from simple shapes and hang fixtures with their GDTF models.
