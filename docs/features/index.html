Features

A lighting desk for Windows that is inspired by the classic console workflow – with a 3D simulation, an effect script language and remote control on top.

Fixtures and programmer

Fixture types come in the open GDTF format. Patch them to a universe and address, select them, and set every function with its own control.

  • GDTF library with manufacturer, device and mode, 16-bit channels, online search in GDTF Share and a preview with the 3D model and gobo and colour wheels. Three built-in generics (dimmer, RGBW par, moving head) are always there.
  • Patching with universe and start address, and a warning when a fixture overflows 512 channels.
  • The programmer gives every GDTF function a control: dimmer, position (pan and tilt coarse and fine, swipe to fine-tune), colour (HSV, CMY or RGB faders, or a colour wheel), beam and focus (shutter and strobe, gobos with preview images, prism, focus, zoom) and direct DMX access.
  • Select by tile, lasso, group or command line. Groups, presets and variables – a variable is a living placeholder: change it once and every place that uses it follows.
  • Aim moving heads by clicking a point on the 3D stage, with automatic focus and zoom for the throw distance.

Cues and executors

Store looks as cues and run them with the executor – several lists at the same time.

  • Cue lists with numbers (also 1.5), names, fade times (separate for colour, position and beam), delay, and triggers: Go, Follow or Timecode.
  • MIB (move in black) and a command of its own per cue.
  • Executor with a mix fader per cue list, Go, Pause, Back and Stop. Cues are tracking: they only contain changes.
  • Store, Update and Delete with dialogs that show what will happen.

Effects and scripting

A real-time effect engine – and a studio to write your own effects.

  • Each effect controls one category: dimmer, colour, position, focus, zoom, gobo and more.
  • 60 ready-made effects come with OpenCue: chase, rainbow, fire, radar, gobo change, zoom pulse and many more.
  • The Effect Studio uses a small C++/Arduino-like language with variables, if, for and while, functions, setup() and loop(), and #RATE. It has a live preview and built-in help.

3D simulation

See the show without any hardware – and plan a stage before you build it.

  • Build a stage from boxes, cylinders, spheres, wedges and a room.
  • Hang fixtures with their real GDTF 3D models.
  • Light cones, light pools, gobos, strobe and focus follow the DMX signal live.
  • Stages are saved as files; undo and redo are built in.

Command line

Everything can be typed: select, set, store, play. Tab completes, and the input is checked as you type.

Fixture 1 Thru 5 At Full Group Front At 80 Zoom 30 Store Cue 3 "Intro" Go Cue 3 Cuelist "Default" Go Blackout On Timecode At 4.3 Play
  • Keypad and command-button panels make the command line usable on a touch screen.
  • Several commands in one line, separated by commas.

DMX output

Network or USB – whatever your rig uses.

  • Art-Net – Network output to nodes and consoles. Switchable; the target IP is yours to set.
  • sACN (E1.31) – Streaming ACN over multicast or unicast. Off by default and only opens its port when switched on.
  • USB DMX – Enttec DMX USB Pro and compatible interfaces.
  • Universes and output – Any number of universes, a dedicated output thread that has priority over the interface, blackout and grand master.
  • DMX monitor – A DMX monitor panel shows the values of the universes live.

Timecode and media

Tie lighting to time, video, audio and cameras.

  • Global timecode – Run, pause, step, 0.1× to 8×, jump. Cues can start by timecode, and there are timecode commands for the command line.
  • Video and audio – A video and audio player panel that runs in sync with the timecode or freely.
  • Cameras and streams – A livestream and camera panel: IP cameras by MJPEG, HLS or video URL, and cameras on the main computer through ffmpeg. Full-screen view included.

Remote control

Operate OpenCue from a tablet or phone in the same network – the very same interface.

  • Same interface, same rights – Password with lock-out after failed attempts, QR code, installable as a web app.
  • Off by default – Switchable at runtime. Live data is throttled for slow devices.

Layouts and themes

The interface is yours to arrange.

  • Free panel layouts with an edit mode, snapping, layers, copy and paste, and undo. Layouts are files; switch with Ctrl+1…9 or by swiping.
  • Your own buttons and faders on the work surface that run commands.
  • Colour themes: dark, light and your own. GUI scaling from 50 to 200 % per device, touch friendly.
  • English and German interface, switchable with Ctrl+Shift+L.

Files and data

Everything is stored as simple, readable files – easy to back up, copy and share.

  • File manager – A file manager for shows, layouts, 3D stages, effects, colour themes and fixtures.
  • Export and import – Export and import a whole show as a ZIP, including the fixture files and effect scripts it needs.
  • Your data folder – The data folder is chosen in the installer and can be moved later in the settings.

Good to know

What OpenCue is not – so nothing comes as a surprise.

Windows only – no macOS or Linux installer.

Version 1.0: test your show before you rely on it live.

Fixture files are not included. You import GDTF files or download them from GDTF Share (a free account there is required).
