Setup

Install, requirements and more

Install in four steps

  1. Download the installer and start it.
  2. Choose the language, the program folder and the data folder.
  3. Finish the setup. OpenCue opens with a small demo show (Default_1 with five dimmers).
  4. Import fixtures in the fixture library, patch them – and light up.

Requirements

  • Windows 10 or 11, 64-bit
  • Microsoft Edge WebView2 Runtime – part of Windows 11; the installer fetches it if missing (internet needed once)
  • For real lights: an Art-Net or sACN network node, or a USB DMX interface

Good to know

  • Windows only – no macOS or Linux installer.
  • Version 1.0: test your show before you rely on it live.
  • Fixture files are not included. You import GDTF files or download them from GDTF Share (a free account there is required).

Run from source

You need Python 3.13 (64-bit) and internet for the first start. run.bat sets everything up.
