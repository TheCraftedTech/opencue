Open-source DMX lighting console for Windows

Program the light. See it in 3D.

OpenCue turns a Windows PC into a complete lighting desk: patch fixtures, program cues and effects, preview the stage in 3D and run the show from a tablet. Free, offline, no account.

Download for Windows View source on GitHub

Why OpenCue

  • Fully offline No account, no licence key, no cloud, no tracking. It works in a venue without internet.
  • Free and open source GNU GPL v3 or later. Read the code, build it yourself, fix it, share it.
  • One interface for desk and tablet The tablet or phone shows the same interface with the same rights – installable as a web app.
  • Readable files Shows, layouts and themes are plain JSON files – easy to back up, copy and share.

Everything a small to mid-size show needs

For bands, theatres, schools, clubs and home studios.

Fixtures and programmer

GDTF fixture library with patching, groups, presets and variables. Every channel gets its own control: dimmer, colour, position, beam, focus, gobo, prism and shutter.

Cues and executors

Cue lists with fades, delays and Go, Follow or Timecode triggers. Run several lists at once, each with its own mix fader.

Effects and scripting

A real-time effect engine with 60 ready-made effects, and an Effect Studio to write your own in a small C++/Arduino-like script language.

Command line

Type commands such as Fixture 1 Thru 5 At Full: Tab autocomplete, input checking, plus keypad and command-button panels for touch screens.

3D simulation

Build a stage, hang fixtures with their real GDTF models and watch beams, light pools, gobos, strobe and focus follow the DMX signal. Aim moving heads by clicking a point on the stage.

DMX output

Art-Net, sACN (E1.31) and USB DMX (Enttec DMX USB Pro and compatibles), any number of universes, with blackout, grand master and a DMX monitor.

Timecode and media

Global timecode that can start cues, a video and audio player panel that follows it, and a camera and livestream panel.

Remote control

Operate from a tablet or phone on the local network, with a password and a QR code. Off by default and switchable at any time.

Your layout

Free panel layouts with an edit mode, colour themes, touch support and GUI scaling. English and German. Export and import whole shows as ZIP.

From install to first cue

  1. Install

    Run the installer. OpenCue opens with a small demo show.

  2. Add and patch

    Import fixtures from the GDTF library and give them a universe and address.

  3. Select and set

    Pick fixtures by tile, lasso, group or command line, then set brightness, colour, position and beam.

  4. Store and Go

    Store looks as cues, add effects, and run them from the executor.

  5. Output or simulate

    Send Art-Net, sACN or USB DMX – or just watch everything in the 3D simulation, no hardware needed.

Download OpenCue

The Windows installer lets you choose the language, program folder and data folder. Later versions update through the same installer, and OpenCue tells you when a new version is out.

Download installer All releases Changelog

Installer file: OpenCue-Setup-v<version>.exe · Newer versions are on the GitHub releases page.

Requirements

  • Windows 10 or 11, 64-bit
  • Microsoft Edge WebView2 Runtime – part of Windows 11; the installer fetches it if missing (internet needed once)
  • For real lights: an Art-Net or sACN network node, or a USB DMX interface

Good to know

  • Windows only – no macOS or Linux installer.
  • Version 1.0 and a one-person project: test your show before you rely on it live.
  • Fixture files are not included. You import GDTF files or download them from GDTF Share (a free account there is required).

Run from source

You need Python 3.13 (64-bit) and internet for the first start. run.bat sets everything up.

git clone https://github.com/TheCraftedTech/opencue.git
cd opencue
run.bat
